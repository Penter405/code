🎯 功能介紹

  • 📊 分析 Git 提交之間的變更文件
  • 📈 統計新增、刪除、修改的代碼行數
  • 🗂️ 跟蹤文件位置和類型
  • 💾 使用 SQLite 數據庫存儲歷史記錄
  • 🔍 支持搜尋和篩選分析結果

🛠️ 技術棧

  • 後端: Python + Git + SQLite
  • 前端: HTML5 + CSS3 + Vanilla JavaScript
  • API: Flask REST API
  • 數據格式: JSON + SQLite

📚 如何使用

  1. 在終端運行: bash /workspaces/code/docs/run.sh
  2. 按照提示選擇提交範圍和分析模式
  3. 等待分析完成，自動打開本頁面
  4. 點擊分析卡片查看詳細信息

🔗 相關文件

  • run.sh - 自動化執行腳本
  • main.py - 主分析程序
  • database.py - 數據庫管理
  • api.py - REST API 服務
  • analysis.db - SQLite 數據庫
